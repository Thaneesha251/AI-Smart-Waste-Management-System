# AI Module

This folder contains all machine learning and deep learning components for the AI Smart Waste Management System.

## Modules

- Waste Detection (YOLOv8)
- Voice Complaint Recognition (Whisper)
- Complaint Priority Prediction (Random Forest)

## Structure

datasets/
Raw and processed datasets.

training/
Training scripts.

weights/
Trained model weights.

inference/
Prediction scripts.

models/
Model-specific code.

notebooks/
Experiments and research.
